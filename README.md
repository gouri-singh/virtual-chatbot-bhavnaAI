# BhavnaAI 🤖

BhavnaAI is an AI-powered virtual assistant designed to understand user commands and provide interactive responses.

## ✨ Features

- 💬 AI-powered conversational interface
- 🎙️ Speech interaction
- 🔊 Text-to-speech responses
- 👤 User authentication and onboarding
- 📷 Camera and photo interaction
- 📹 Video call interface
- 🌐 Information search and assistance
- 🎨 Interactive and user-friendly UI

## 🛠️ Tech Stack

- React.js
- JavaScript
- Vite
- HTML5
- CSS3
- Git & GitHub
